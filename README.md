# Christmas Overlay (Fabric 1.21.11, client only)

Butterfly-knife skins (15) with hand tricks, Christmas mining overlay + particles, galaxy night sky,
Christmas hearts/hunger bar, camera zoom-out, visual swing speed. Works with Mod Menu (Configure button).

Keys (change in Options > Controls, or in the menu's Keys tab):
- **J** open the settings menu
- **G** hold to do knife tricks (needs the totem/knife in your main hand; empty hand = chat message)

Build: push to GitHub, Actions builds the jar (Actions > latest run > Artifacts). Put the jar in `mods`.
Needs Fabric Loader + Fabric API. Mod Menu is optional.
If a feature errors it switches itself off and tells you in chat instead of crashing.
